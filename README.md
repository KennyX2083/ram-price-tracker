# RAM Deal Tracker

A Python app that checks DDR5 laptop RAM prices across retailers and sends Discord alerts for when specific price events occur.

## Features

- Best Buy API support
- Micro Center support
- Amazon support
- Newegg support
- SQLite price history
- 30-day moving average
- Discord webhook notifications
- Automatic deal detection

## Planned retailers

- Best Buy
- Amazon
- Newegg
- Micro Center

## Tech Stack

- Python
- SQLite
